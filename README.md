# JEE Main 2027 Planner (Physics, Maths, Chemistry)

A single-file web planner (`index.html`) that builds an exam-dated JEE Main Physics plan from a student's start date, daily hours and chapter-wise preparation.

- Progress ticks (Done / In progress / Skipped) and the plan are saved in the student's browser.
- **Re-plan from today** re-packs unfinished chapters into the days left, keeping the original end date.
- **Download as PDF / HTML** below the plan.
